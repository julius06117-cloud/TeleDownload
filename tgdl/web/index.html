还没有可用的登录

这个页面不能接收验证码。在终端完成一次登录，然后刷新。

  1. 如果 tgdl serve 正在运行，先在那个终端按 Ctrl+C。会话文件同一时间只能由一个进程使用。
  2. 执行 tgdl login，按提示输入手机号、验证码，以及两步验证密码（如果开了）。
  3. 再执行 tgdl ui，或 tgdl serve --open。

api_id 和 api_hash 写在 .env 或 config.yaml。不要提交到 git，也不要发到聊天里。

还没有读取。点「读取群组」从当前账号拉取对话。

扫描

选出要看的群，或直接填 @用户名、公开链接、邀请链接、数字 id。邀请链接会让当前账号加入那个群。扫描只列出文件，不写入磁盘。

默认只处理文档，包含以文件形式发送的视频和音频，不包含图片。

下载

使用扫描页里的目标和筛选。同一条件再跑一次时，已经下完且大小一致的文件会跳过，半成品从断点续传。

并发过高通常不会更快，反而容易被 Telegram 要求等待。中断后进度留在 .part 和旁边的 .tgdl.json 里。

任务

暂停或中断之后，状态是「已暂停」。点「继续」会接着已有的半成品下。速度只在下载进行中更新，停下来就是 0。
